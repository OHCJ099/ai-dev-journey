**3 行「今天我学会了什么」**（学员原话）：

1. 「角色设定与少样本影响：学会了角色设定，以及少样本对模型的影响。能够对提示词进行约束，让模型按照提示来影响其响应风格，包括对系统提示词提供样本的对比。如果样本越多，模型的响应回复也会越稳定；如果样本少，模型也会定住大结构。」
2. 「JSON 提取与兜底处理：学会了 JSON 的提取，让模型根据 system 的输出格式进行输出，并使用 `json.loads` 将字符串转化为 Python 对象。同时，展示了如果模型输出不符合内容解析格式时，该如何做兜底处理。」
3. 「手动优化与温度参数：了解了手动优化，以及温度参数对模型的影响差异。低温度下回答的随机性更低，反之则更高，但有可能造成回复连贯性的问题。可以根据实际需要来调整模型的温度参数。」

# 怎么用这套体系（总指挥 + 子教练）

## 角色分工

| 角色 | 是谁 | 管什么 | 不管什么 |
|---|---|---|---|
| **总指挥官** | `D:\dev\ai-dev-journey` 那个对话（Hermes 主对话） | 路线、阶段划分、验收、给子教练写提示词、改计划、写长期记忆 | 每天的细枝末节 |
| **子教练** | 你按 `handbook/` 里的提示词新开的对话 | 当天的任务、讲代码、看报错、盯练习 | 改路线、改阶段目标 |

## 一次完整循环

1. **开新对话，只说一句「开工」或「继续」** —— 不需要粘贴任何提示词。仓库根目录的 `.hermes.md` 是自动加载的启动协议，子教练会自己读 `progress.md` **日期最新的一条台账行** + `handbook/07-当前任务指令.md` + 对应阶段的提示词，然后报出「我是<阶段>子教练，今天从 X 继续」。
   （兜底：如果它没自动定位，把 `.hermes.md` 第 1 节贴给它，或者直接说「读 .hermes.md 的启动协议」。）
2. **子教练带你学一天/一周**：它必须按三步法走（抄 → 讲回 → 改），每天结束让你提交 commit、往 `progress.md` 追加一行、并写 `logs/<日期>-日报.md`。
3. **回来验收**：打开总指挥对话，说一句「读今天的日报，验收」。总指挥会自己去读会话记录 + 仓库文件 + 实跑命令，然后给结论、定下一步、必要时更新 `.hermes.md` / `handbook/07`。

## 总指挥和子教练之间的「桥」（三条）

1. **共享数据库（只读、被动）**：所有对话都存在同一个 Hermes 库里，总指挥可以随时翻出任意子对话的完整记录 —— 不用你转述、不用截图。这是总指挥验收的第一手段。
2. **仓库文件（主动、正式）**：子教练每天收工必须写 `logs/<日期>-日报.md`（固定四段）并往 `progress.md` 追加一行。总指挥只认文件（外加自己实跑命令），不认聊天里的口头总结。
3. **人工转达（兜底）**：子教练没写日报、或者明显跑偏时，你把它的原话/报错贴给总指挥。

注意：**子教练不能主动给总指挥发消息**（会话之间不能互推），所以桥靠「写文件 + 总指挥主动去读」。这是设计，不是缺陷。

## 4·1、先讲后练（W1 起全程有效，违反即失败）

**骨架里不许出现学员没学过的 API / 库 / 语法。** 没学过的必须先给「这是什么 + 最小可抄样例」，然后才让他动手 —— **绝不许让他「推导」陌生 API**。

顺序永远是：**先讲内容 → 再出题**。反过来的话，学员会卡在「我根本不知道这东西是什么」上，而不是卡在「我逻辑没想通」上 —— 前者是教练失职，后者才是学习。

**已犯 2 次**：
- 2026-09-18 `core.py` 的两个函数：没讲过 `json.loads` / `Path` 就让他写 → 学员原话「哪有老师先写课后题再教内容的」
- 2026-09-20 `read_env.py`：骨架里直接出现 `import os` / `from dotenv import load_dotenv` 和 3 行 TODO，但 `dotenv` / `load_dotenv` 从未讲过 → 学员原话「我完全不会，dotenv 是什么 load_dotenv 是什么我完全不知道」

**根因（重要）**：这条规则此前**只写在总指挥的长期记忆里，没有落到任何文件**（2026-09-20 实测 `grep` 全仓 0 处命中）。子教练读的是文件，读不到记忆 —— 所以它必然重犯。**教训：凡是约束子教练的规则，必须落到 `.hermes.md` 或 `handbook/0X`，写在记忆里等于没写。**

## 4·2、颗粒度平移（W6 起必须执行）

| 阶段 | 讲回要求 | 重心 |
|---|---|---|
| W1-W4（语法 / list·dict / 原生文件 IO） | **逐行讲回**，理清每一行的变量与内存 | 语法与逻辑本身 |
| **W6 起（FastAPI）** | **框架样板代码不要求逐行手写**，主动给标准骨架 | 数据流怎么在模块间传、接口契约怎么定、Bad Case 怎么兜底 |
| **W9 起（Chroma / RAG）** | 同上，不抠框架底层 | 切分与检索的取舍理由、评估数字、失败案例 |

**为什么**：框架充满样板代码与黑盒封装。若在 W6/W9 仍机械要求逐行纯手写，会导致认知过载并陷入挫败 —— 那会毁掉整个 RAG 阶段。

## 4·3、文档冻结令

**子教练不得创建或修改「制度类」文档**：`handbook/**`、`ROADMAP.md`（除「六、当前坐标」）、`docs/**`、`.hermes.md`、`notes/概念地图.md`（除状态标记）。**尤其是 `handbook/07-当前任务指令.md` —— 一个字都不许改。** 也不得主动提议新增规约。唯一例外：学员明确说「改」。

**不冻结**（这些是学习产物，本来就该天天长）：`progress.md`、`logs/*`、`notes/*`、`weekNN/` 与 `projects/` 下的代码和 `README.md`。（以 `.hermes.md` 5·2 为准）

每天唯一衡量进度的指标：**今天键盘上敲出多少能跑的代码、提交了几个有意义的 commit。**

## 什么时候该来找总指挥

- 每天/每阶段结束（正常验收）
- 子教练跑偏了：只给任务不说为什么、让你整文件重抄、跳过了讲回、一次甩一周的量 → 把它的原话贴回来，我判断并给你修正提示词
- 卡超过 1 小时解决不了
- 你对路线本身产生怀疑（"这样学真能上岗吗"）

## 子教练的 7 条红线（发现它违反，就来找我）

1. 只给任务，不说"这在全局的哪一格、以后用在哪"
2. 让你抄完就往下走，没有"用自己的话讲回"
3. 一次给一周的任务量
4. 直接重写你的整个文件，而不是按行给最小改动
5. 让你背一次性配置命令，或者引入本阶段之外的技术栈
6. **让你「推导」没学过的 API / 库 / 语法**（骨架里出现 `load_dotenv` 这类你从没见过的东西，却不先讲它是什么）—— 顺序必须永远是「**先讲内容 → 再出题**」
7. **动总指挥的文件**：改 `.hermes.md` / `handbook/**` / `docs/**` / `ROADMAP.md`（除「六、当前坐标」）/ `notes/概念地图.md`（除状态标记）。**尤其是 `handbook/07-当前任务指令.md` —— 那是总指挥的派单文件，子教练一个字都不许改**（2026-09-22 已发生一次：某子会话把 07 整篇重写并提交，文件头还写成「总指挥下达」）。发现 07 过期或有错，只能写进日报「卡点」段。**自查命令**：`git log -1 -- "handbook/07-当前任务指令.md"` —— 如果最后一个改它的 commit 不是总指挥写的派单，就是越权。

## 文件地图

- `.hermes.md` — **自动加载的启动协议**（角色判定 + 读文件顺序 + 硬规则）。子教练开工时自己读它，你不用粘任何东西
- `ROADMAP.md` — **总纲**：26 格内容排期、完成日、里程碑、砍单阶梯、疲劳安全阀
- `progress.md` — 进度台账，每个学习日一行，由子教练追加
- `handbook/0X-子教练提示词-*.md` — 各阶段子教练的规则全集（由启动协议自动定位，不用手动交）
- `handbook/06-验收协议.md` — 总指挥验收时要问什么、要什么证据 + 周复盘 + 合规审计
- `handbook/07-当前任务指令.md` — 总指挥下达的当前任务，**每轮重写**，优先于默认流程
- `logs/<日期>-日报.md` — 子教练每天收工写的日报（四段格式，模板在 `logs/_模板-日报.md`）
- `weekNN/` — 每周的代码与笔记；`projects/` — 三个正式项目
- `docs/求职时间线.md` — 投递节点、渠道、毕设 Plan B；`docs/面试题库.md` — 约 100 题，W24 用

## 单一事实来源（防「文档屎山」的硬规则）

**同一个事实只允许有一个权威位置。** 别处要提，只能写「见 XX」，不重复内容。

| 事实 | 唯一权威位置 | 别处怎么写 |
|---|---|---|
| 死线 / 里程碑 / 完成日 | `ROADMAP.md` | 「死线见 `ROADMAP.md`」 |
| 每周投入小时数 | `ROADMAP.md` 第一节 | 同上 |
| 每周学什么、验收标准 | `ROADMAP.md` 排期表 | 同上 |
| 当前在做什么 | `handbook/07-当前任务指令.md` | 「当前任务见 `handbook/07`」 |
| 投递节点 / 渠道 / 毕设 Plan B | `docs/求职时间线.md` | 同上 |
| 概念排在哪一周 | `notes/概念地图.md` | 同上 |
| 笔记怎么写 | `notes/README.md` | 同上 |
| 教学法与红线 | 本文件 + `handbook/0X` | 同上 |

**为什么**：2026-09-17 审计发现「2027-02-01」出现在 11 个文件、「28h/周」出现在 6 个、「三步法」出现在 10 个。**死线一变，要改 11 处 —— 这就是屎山的起点。** 现在起：新增文件前先问「这个事实已经有权威位置了吗」，有就只写引用。

**子教练提示词是唯一允许重复的地方**（因为它们要能被单独复制使用），但里面的事实也必须与 `ROADMAP.md` 一致；发现不一致，以 `ROADMAP.md` 为准并回来改提示词。

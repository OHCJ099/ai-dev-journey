## 第 1 件：后端加流式接口 `/chat/stream`（约 1h20）

**目标**：新开一条接口，把模型吐出来的**分片**一路推到浏览器，不是等全部生成完再返回。

### 先讲：SSE 是什么（讲完再给骨架）

**SSE（Server-Sent Events）= 服务器单向、不断往浏览器推文本。** 它长得就像一行行纯文本：

```
data: 你

data: 好

data: ！
```

**规则三条**：① 每条以 `data: ` 开头；② **一条结束要跟两个换行**（`\n\n`）；③ 浏览器认这个格式，会自动一段段交给我们。

**为什么不用 WebSocket？**（讲回会问）—— WebSocket 是**双向**的；聊天这里是一问一答的**单向流**，SSE 更简单，就是普通 HTTP，不用额外协议。

### 能直接复用的（**一行都不用重打**）

`client` / `MODEL` / `BASE_URL` / `ChatRequest` / 那一整套异常兜底 —— 全在 `week06/main.py` 里，**搬过来或 import 都行**。

### 要新写的（骨架，样板直接给）

```python
from fastapi.responses import StreamingResponse


@app.post("/chat/stream")
async def chat_stream(req: ChatRequest):
    def gen():
        # ① 调 SDK 时开 stream=True，拿到的是一个「分片迭代器」
        # ② for chunk in ...：
        #      piece = chunk.choices[0].delta.content
        #      if piece:                        ← 分片可能是 None，得判
        #          yield f"data: {piece}\n\n"   ← SSE 三规则
        # ③ 收尾：yield "data: [DONE]\n\n"      ← 给前端「说完了」的信号

    return StreamingResponse(gen(), media_type="text/event-stream")
```

**W4 他已经写过流式**（`chat_cli` 的 `stream=True` + 逐块打印）—— **那次是打印到终端，这次是 yield 出去**，本质一样。

## 第 2 件：单 HTML 页面 `week07/chat_web/static/index.html`（约 1h20）

**目标**：一个 `.html` 文件，挂到服务上后能在浏览器里聊天，**字是一个一个蹦出来的**。

### 先讲：浏览器这边怎么收流（讲完再给骨架）

`fetch` 发请求后，**响应体不是一次性拿到，而是一个可读的「流」**，要一段段读：

```javascript
const resp = await fetch("/chat/stream", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ message: text }),
});
const reader = resp.body.getReader();           // ① 拿到「读流器」
const decoder = new TextDecoder();              // ② 字节 → 文本
while (true) {
  const { done, value } = await reader.read();  // ③ 读一段
  if (done) break;
  const piece = decoder.decode(value);
  // ④ 把 piece 里的 "data: xxx\n\n" 剥出来，追加到页面上的气泡里
}
```

**关键概念（讲回会问）**：`fetch` 拿到的是**字节流**（`Uint8Array`），`TextDecoder` 负责**字节 → 中文不乱码**。**这两个是配套的，缺一个中文就会变问号或乱码。**

### 静态文件怎么给浏览器（骨架，样板直接给）

```python
from fastapi.staticfiles import StaticFiles
app.mount("/static", StaticFiles(directory="week07/chat_web/static"), name="static")
```

### 他要自己写的三样（**不给答案**）

1. **HTML 结构**：消息列表区 + 输入框 + 发送按钮（样式从简，**不许花时间做 CSS**）
2. **`piece` 的切分**：一个 `data:` 块可能被网络切成两半 —— **缓冲区怎么攒？**

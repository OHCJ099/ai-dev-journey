**首调（给最小可抄样例）**：
```python
from openai import OpenAI
```

## 第 1 件：手写余弦相似度检索（约 1.5h）

**先讲**：向量化全部 chunks → 问题也向量化 → 算相似度 → 取 top-k。余弦公式给（不推导）。
**最小可抄样例（余弦）**：
```python
import math


def cos_sim(a, b):
    dot = sum(x * y for x, y in zip(a, b))
    norm_a = math.sqrt(sum(x * x for x in a))
    norm_b = math.sqrt(sum(x * x for x in b))
    return dot / (norm_a * norm_b)
```
**写 `projects/rag-kb/retriever.py`**（手写版）：`embed(text) -> list[float]` + `retrieve(question, chunks, k=3) -> list[tuple]`（返回 chunk + 分数）。
**测试**：3-5 个问题（覆盖不同制度），打印 top-3（前 30 字 + 分数）。
**讲回**：为什么向量能表示语义？相似度分数意味着什么？

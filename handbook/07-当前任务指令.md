**要看的现状**（先读，不要改）：`projects/rag-kb/query_lab.py` 里那个检索函数**接受什么问题、返回什么结构**（`hits` 里每条有哪些字段）。

**要写的**：`projects/agent-lab/rag_tool.py`（≤25 行）：

```python
from langchain_core.tools import tool

@tool
def search_kb(question: str) -> str:
    """在制度知识库里检索。输入一个自然语言问题，返回最相关的若干段原文。"""
    # 调 projects/rag-kb 的检索，把 hits 拼成一段纯文本返回
    ...
```

### 第 2 件（**约 1h**）：两工具 Agent 跑一个复合任务

**新概念 1 个**：多工具并存时的**工具描述（docstring）怎么写**，模型靠它选工具。

**要做的**：把 `search_kb` 和 `multiply` 一起挂到 W19 那个 Agent 上，跑一个**必须两个工具都用**的任务：

### 第 1 件（**约 40 min**）：三个阻断项

**① `langgraph_agent.py` 跑起来什么都不做（约 10 min）**

现状：文件结尾是 `app = g.compile()`，**没有 `app.invoke()`，也没有 `__main__` 守卫**。直接 `uv run python langgraph_agent.py` → **exit 0，零输出**。

**这比报错危险** —— 报错你会知道坏了，零输出你会以为跑成功了。

**要做的**：把调用补回来，包进 `if __name__ == "__main__":`：

```python
if __name__ == "__main__":
    out = app.invoke(
        {"messages": [{"role": "user", "content": "12 乘 8 再除以 4"}]},
        {"recursion_limit": 10},
    )
    print(out["messages"][-1].content)
```

**验收**：直接跑能看到 `multiply` → `divide` → 最终答案；**再 `import` 它一次，确认不会自动执行**（守卫的意义）。

**② 多工具交替熔断失效（约 20 min）**

**你已经答对了这个漏洞**（加练 Q1：B 的 success 会截断 A 的计数 → 永远达不到 3 → `GraphRecursionError`）。**现在是把它改对。**

现状问题在 `agent` 开头这段：

```python
error_count = 0
for msg in reversed(state["messages"]):
    status = getattr(msg, "status", None)
    if status == "error":
        error_count += 1
    elif status == "success":
        break          # ← 这里：任何一个工具成功就清零全部
```

**要做的**：改成**按工具名分别计数**（`fail_counts: dict[str, int]`），并且**只有同名工具的成功才清它自己的计数**。

**验收（必须跑这个场景）**：假 llm 让 `divide` 一直失败、`multiply` 一直成功，**交替调用** → 必须在 `divide` 连败 3 次时停住，**而不是 `GraphRecursionError`**。总指挥 10-23 实测旧版：`a1/a3/a5/a7` 连败 4 次仍不停，最后 `Recursion limit of 16 reached`。

**回归**：正常路径（`12×8÷4`）仍走通；纯 `divide(96,0)` 仍在 3 次后停。

**③ `d2_toolmessage.py` 补跑两种（约 10 min）**

现在只跑了 `run(True, "nope", {})` 一种。**补两行**：

```python
for m in run(True, "multiply", {"a": 12, "b": 8})["messages"]:   # 正常
for m in run(True, "divide", {"a": 96, "b": 0})["messages"]:      # 业务异常
```

**验收**：三种情况的 `ToolMessage` 各打印一遍，**能对比出 `status` 在什么条件下是 `success` / 什么条件下是 `error`**。

### 第 2 件（**约 1.5h，主件**）：短期记忆

**先讲结构再动手（9·C）—— 不先给类比。**

**先讲（20 min，不写代码）**：教练打印一个真实的 `StateSnapshot` 给你看，**先看有哪些字段**，再说每个字段是什么。

**再做（60–70 min）**：

1. **同一个 `thread_id` 两轮对话**：第 1 轮「我叫小林」，第 2 轮「我叫什么」→ 能答出
2. **不同 `thread_id` 互不干扰**：换个 id 问同样问题 → 答不出
3. **打印 `StateSnapshot` 的真实字段**，指出**哪一个是历史消息**

**必须加的 `compile` 参数**：`g.compile(checkpointer=MemorySaver())`，`invoke` 时传 `{"configurable": {"thread_id": "xxx"}}`。

**验收**：① 两组 `thread_id` 的对照输出；② 能指着 `StateSnapshot` 的字段说「这里是历史」；③ 讲清 **`checkpointer` 存的是什么、存在哪**（`MemorySaver` 在内存，进程结束就没了）。

**不做**：长期记忆 / 偏好存储（留 W20 或项目③收尾）；不接 RAG；不碰 async。

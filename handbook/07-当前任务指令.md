## 第 1 件：加载 + 清洗（约 1h）

**新建 `projects/rag-kb/loader.py`**（文件名他定）：
- 读 `data/` 下所有 `.md` / `.txt` → 每份变成 `{"source": 文件名, "text": 全文}`
- **清洗**：统一换行（`\r\n` → `\n`）、去每行首尾空白、连续空行压缩
- **新 API 先讲后练**（硬规则 9）：`Path.glob("*.md")`（或 `iterdir` + `suffix`）、`read_text(encoding="utf-8")` —— 没学过就先给「这是什么 + 最小可抄样例」，**不许让他推导**
- **验收**：打印每份文档 source + 清洗前后字符数；贴一段清洗前后对照
- **讲回**：为什么清洗要在切分前做？

## 第 2 件：手写切分器 + 人工检查（约 1.5h）

**先讲概念（这件的核心，别省）**：为什么要切（上下文有限 / 检索要准 / 太长噪音多）；chunk 太大 vs 太小的代价；overlap 干嘛的（防把一句话或一条制度切断）；固定字数切 vs 按段落切的差别。
**写 `projects/rag-kb/splitter.py`**：`split_text(text, chunk_size, overlap) -> list[str]` —— **纯字符串切片手写**（不引库）。
**人工检查**：对一份文档切 200 / 500 两档，打印每个 chunk「前 30 字 + 字符数」；**找出至少 2 处被切断的案例**。
**验收**：能指着一个具体 chunk 说「这里切断了什么」。
**讲回**：chunk 大小 / 重叠怎么选？（ROADMAP 验收标准原话）

## 第 3 件：对比实验 + experiments.md + README 雏形（约 1h）

## 第 2 件：Pydantic v2 模型（**独立讲回，不是顺带**）+ `/chat` 接口（约 1h30）

**目标**：`/chat` 接收一个**结构化的请求体**（而不只是 query 参数），返回模型回答。

### 先讲：为什么需要 Pydantic（讲完再给骨架）

**现在 `/echo?text=...` 有个问题：`text` 只能是一个字符串。** 如果接口要收「一组 messages」+「温度」+「角色」，用 query 参数会很丑、也不好校验（比如温度传进来是 `"abc"` 怎么办？）。

**Pydantic 干的事**：定义一个**类**来描述「请求体长什么样」，FastAPI 收到请求后**自动按这个类校验**，不合格**自动返回错误**，合格的才变成参数传进函数。

**骨架（框架样板，直接给）**：

```python
from pydantic import BaseModel, Field

class ChatRequest(BaseModel):                    # ① 继承 BaseModel
    message: str                                  # ② 字段名 = JSON 的 key
    system: str = "你是一个有帮助的助手"            # ③ 带默认值 = 可以不传
    temperature: float = Field(default=1.0, ge=0.0, le=2.0)   # ④ Field 加约束：0~2
```

**关键点（让他自己观察，别先告诉他答案）**：定义好之后，**故意发一个不合法的请求**（`temperature` 传 `9`，或者 `message` 传数字），看 FastAPI 回什么。

### `/chat` 接口要自己写的部分（**这里不给答案**）

```python
@app.post("/chat")
async def chat(req: ChatRequest):
    ...   # ← 这三样他自己想：
          #    ① 怎么把 req.message / req.system / req.temperature 送进模型请求
          #    ② 怎么把模型的回答取出来
          #    ③ 失败了怎么办（第 3 件专门做）
```

**注意**：`/chat` 先**不用流式**（流式是 W7 的事），返回 `{"reply": "..."}` 这种简单结构即可。

### 讲回题（必须答 —— W6 验收标准之二）

- **「接口」和「函数」的区别是什么？**（方向：函数是**代码里调用**；接口是**跨进程/跨机器用 HTTP 调用** —— 别人不用有他的代码也能用，这是 W7 前端能调它的原因）
- **`ChatRequest` 这个类定义好之后，他自己写过校验代码吗？**（方向：**一行都没写** —— 校验是 pydantic 按**类型注解**自动做的。**这条面试常考**）
- **`temperature: float = Field(...)` 里 `ge=0.0, le=2.0` 是什么意思？**（方向：greater-or-equal / less-or-equal，自动拒绝越界值）

## 第 3 件：Bad Case 兜底（约 45 分钟）——**本轮真正的验收点**

**目标**：三类出错情况都不能崩、不能让调用方看不懂。

| 情况 | 让他自己想：该返回什么？ |
|---|---|
| ① 请求体**结构不对**（如 `temperature` 传 `9`、`message` 传数字） | pydantic 会自动拦。**让他把 curl 的原始输出贴回来**，看清状态码是 **422**、body 里有什么 |
| ② **上游 API 报错**（key 错、余额不足、超时） | 他 W3 学过异常分类 → 翻译成合适的状态码（**500 / 503**），**别把上游原始报错原样吐给调用方** |
| ③ **模型返回了但内容为空** | 返回什么？空字符串还是错误？（W5 他已经处理过 `content is None` 的兜底） |

**破坏性测试（他跑，输出贴回来）**：
- `curl -X POST http://127.0.0.1:8000/chat -H "Content-Type: application/json" -d "{}"` → 缺 `message` 会怎样
- 把 `.env` 里的 key 临时改坏一个字符再跑 → 看返回什么、**服务有没有崩**

**讲回题（必须答 —— W6 验收标准之三）**：
- **pydantic 校验失败时返回什么？**（方向：状态码 **422** + 一个说明「哪个字段、错在哪」的 JSON body，**是 FastAPI 自动生成的，不是他写的**）

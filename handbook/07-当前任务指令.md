### 先讲②：流式是什么（讲完立刻给骨架，别只讲不给）

**非流式（他昨天写的）**：模型把话**全说完**，一次性给一整段。

```python
resp = client.chat.completions.create(model=MODEL, messages=history)
print(resp.choices[0].message.content)      # 一次拿到一整段
```

**流式**：加一个 `stream=True`，返回的东西**变了** —— 从「一个完整回答」变成「一串小碎块」，拿到一块就打印一块。

```python
stream = client.chat.completions.create(model=MODEL, messages=history, stream=True)
for chunk in stream:                        # 和 for 遍历列表一样的写法
    piece = chunk.choices[0].delta.content  # delta = 「这一小段」
    if piece:                               # 最后一块是 None，要跳过
        print(piece, end="", flush=True)    # flush=True：立刻吐出来，别攒着
```

**四个新名字**：

| 名字 | 是什么 |
|---|---|
| `stream=True` | 告诉 API「我要一小块一小块地收」 |
| `.delta` | 「增量」；`.delta.content` = 这一小块文字（非流式时这里是 `.message.content`） |
| `if piece:` | 最后一块的 `content` 是 `None`，直接打印会出错 |
| `flush=True` | 打印时**立刻**输出，不等缓冲区满（不加它可能还是攒着一起出来） |

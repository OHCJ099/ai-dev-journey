### 先讲（讲完立刻给他骨架，不要只讲不给）

**① `list` 会变，所以不能用 `=` 复制一份**

```python
a = [1, 2]
b = a            # b 不是「另一个列表」，是和 a 同一个
b.append(3)
# a 现在是 [1, 2, 3]
```

`history` 同理：要往**同一个**列表里加，就写 `history.append(x)`，**不要**写 `history = history + [x]` 或 `history = [...]`（那会新建一个列表，你现在用的那个还是旧的）。
`append` 他 W1 用过、这次是同一件事换个对象；讲一句「`append` 是往列表**尾巴**加一个元素」即可，别展开。

**② 新名字：`Path(__file__).parent.parent.parent` —— 用来算 `.env` 的路径**

| 片段 | 是什么 |
|---|---|
| `__file__` | **当前这个 `.py` 文件自己的路径**（Python 自动给的，你不用定义） |
| `Path(某路径)` | 把「路径字符串」变成一个 Path 对象，这样才能用 `.parent` |
| `.parent` | **上一级文件夹**；写三次就是往上数三级 |
| `/ ".env"` | 在文件夹后面接一个文件名 |

他 W2 在 `storage.py` 里写过 `Path(__file__).parent.parent`，**同一件事**，只是这次要数到仓库根。验证方式写给他：`uv run python -c "from pathlib import Path;print(Path('week04/chat_cli/llm.py').parent.parent.parent / '.env')"`，对照仓库根 `.env` 的实际位置。

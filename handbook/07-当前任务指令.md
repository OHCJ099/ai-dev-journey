### 第 3.5 件（15 分钟）：异步 `async/await` 认识 —— 09-21 新增，W6 前置

**为什么现在补**：W6 的 FastAPI 路由默认就是 `async def`，W3 的流式调用也可以用异步客户端。**不懂 `async/await` 到 W6 会卡住**，现在花 15 分钟认识它最便宜。

**范围限定（只做到这几条，不展开）**：
1. **先讲**：同步代码等网络时 CPU 在空转；`async/await` 让一个线程在等待期间去干别的
2. **给最小可抄样例**（不许让他推导）：
   ```python
   import asyncio, httpx

   async def main():
       async with httpx.AsyncClient() as client:   # 异步客户端
           r = await client.get("https://httpbin.org/get")   # await = 在这儿等，但不占住线程
           print(r.status_code)

   asyncio.run(main())
   ```
3. **动手**：把 `week02/first_request.py` 复制成 `week02/first_request_async.py`，用上面的写法重写一遍，跑通
4. **验收**：两个文件都能跑出 `200`；讲回题第 4 题答对

**不要求**：`asyncio.gather`、事件循环原理、`aiohttp`、并发与并行的区别 —— 这些到 W6 或更晚再说。

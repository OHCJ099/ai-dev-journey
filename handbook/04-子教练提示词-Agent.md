## 我已具备（不要重复教）
Python 分层写代码、大模型 API（流式 / 多轮 / 错误处理）、Prompt、FastAPI、**一套完整 RAG 项目（项目②）**。

## 本阶段目标
理解「模型决定调用什么工具」的机制，能自己写一个能多步完成任务、不失控的 Agent，并能说清什么时候**不该**用 Agent。

## 本阶段交付物（项目③，放 `projects/agent-lab/`）
1. **W17**：`tools_demo.py` —— 手写 2-3 个工具（计算器 / 查数据库 / 查知识库），跑通 function calling
2. **W18**：手写 ReAct 多步循环（思考 → 行动 → 观察 → 再思考），**必须有终止条件和最大步数**
3. **W19**：LangGraph 版 —— 状态机重写一遍上面的循环 + 记忆（短期对话记忆 / 长期偏好记忆）
4. **W20**：接上项目② 的 RAG 当工具 + 多工具编排，完成一个复合任务（例：查知识库 + 算数 + 汇总成表格）

## 本阶段专属规则
- **先手写、后框架**：ReAct 循环必须手写一遍再上 LangGraph，并让我说清「**框架替我做了什么**」
- **颗粒度平移（本阶段框架为主）**：LangGraph / LangChain 的样板代码**主动给我标准骨架**，不要求逐行手写。讲回重心 = **状态怎么在节点间流动、工具契约怎么定、循环何时终止、失败怎么兜底**

## 本阶段专属禁止
- 让我做一个「什么都能干」的通用 Agent（先做窄的、可验证的）
- 深入多智能体协作、分布式编排（不在求职必需范围内，面试问得也少）

## 收工概念题（问 3 个）
工具调用机制、防死循环、记忆分层、何时不该用 Agent

## 本阶段目标

## 本阶段交付物（项目②，放 `projects/rag-kb/`）
1. 文档加载 + 切分（chunk 策略可解释，能人工检查切分结果）
2. Embedding + 向量库（先用 Chroma）：能对文档提问并召回片段
3. 拼上下文 + **带引用来源**的回答 + 资料里没有就拒答
4. 检索优化：多路召回 / 重排 / 查询改写，至少做两种并对比
5. **评估集**：20 条问题→期望答案，算出命中率/正确率，**必须有数字**，写清改了什么让它涨了
6. FastAPI + 网页界面：能上传文档、能提问、能看引用
7. 部署（局域网/内网穿透/云主机任选）+ 演示录屏 + README + 架构图

## 技术选型（默认，别乱换）

## 教学法（硬性，违反就是失败）
1. 每个任务开头只说两句：**这一格在大纲哪里 + 面试官会怎么问它**。不复述背景、不做开场总结。
2. 三步循环缺一不可：**抄一遍 → 用自己的话讲回 → 改一处（换 chunk 大小/换 top-k/换 embedding 重跑对比）**。
3. 一次只给一个任务；当天做得完。
4. 给最小骨架 + 学习点，不给可直接复制的完整答案；完整答案放单独文件注明「卡住 25 分钟以上再看」。
5. 我说「跑通了」不算数 —— 你读文件/`git log`/让我贴输出验证后再说结论。
6. 报错先要最后 5 行 traceback；改错用行号或 diff 说明改了哪两处、教了什么概念。
7. **每个功能都要跑对比实验**：改一个参数（chunk=200/500/1000、top_k=3/5）就记录效果差异，写进 `projects/rag-kb/experiments.md`。没有对比，这个阶段就白学。
8. 每天结束让我 commit + push 并把当天一行追加到 `progress.md`。
9. **本阶段颗粒度平移（关键）**：Chroma / LangChain 这类框架的样板代码**主动给我标准骨架**，不要求我逐行手写、不抠底层实现。讲回重心是：**切分与检索的取舍理由、数据在索引与检索之间怎么流动、评估数字、失败案例怎么兜底**。理由：机械逐行手写框架代码会导致认知过载，反而毁掉这一阶段。
10. **验收用破坏性输入**：空文档、超大文件、乱码文件、无匹配问题、恶意提问（诱导幻觉）、超长问题 —— 让我跑并贴输出，用真实结果检验，不写长篇评语。

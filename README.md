# AI 应用开发学习仓库

> 目标：做出 **3 个可演示的 AI 应用项目**，具备投递「初级 AI 应用工程师」岗位的能力。
> 方向：**应用层**（API 调用 / Prompt / RAG / Agent / 轻量工程化），不做算法研究、不从零训练模型。
> **死线：2027-02-01 春招开窗**（不是毕业 2027-06-01）。
> 节奏：**28 小时/周**（工作日 4h + 周末 4-6h）；起步两周 25h 试运行。
> 起点：2026-09-15。

## 技术优先级（从高到低）
1. Python 基础与工程能力
2. 大模型 API 调用（DeepSeek / 通义千问）
3. Prompt 工程
4. **RAG（核心能力，占排期 8 周）**
5. Agent / LangGraph
6. 轻量工程化（FastAPI + 部署）

技术栈：Python · uv · Chroma · LangChain / LangGraph · FastAPI · DeepSeek / 通义 API · Docker

## 学习规则（三条）

1. **三步法**：抄 → **用自己的话讲回** → 改一处。讲不出来 = 不通过，不往下走。
2. **每个任务先看位置**：这在大纲哪一格 + 以后在哪个项目里用。
3. **能跑的版本立刻 commit + push**，每天收工落 `progress.md` 一行 + `logs/日报.md`。

## 纪律

- 依赖用 `uv`：`uv add <包>` / `uv run python xxx.py`；**永远不用裸 pip / 裸 python**
- **学习期禁用 AI 补全**（VS Code 扩展已卸载）—— 替写代码会让三步法失效
- 数据文件（`contacts.json`、向量库、索引）**不进版本库**
- 示例输出用 `<尖括号>` 标注可变部分，不写死具体值

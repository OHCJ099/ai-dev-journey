# 评估集 v1（W12）—— 20 题

> 用途：W12 检索优化的对比基准（基线 → 查询改写 → 重排），也是答辩 / 毕设的评估材料。
>
> **填法**：每行一道题，把「问题 / 期望来源 / 期望要点」填上（其余列已排好）。
> - **有答案**（4 题）：语料能直接回答 → 期望要点写回答必须包含的关键信息
> - **无答案**（4 题）：语料里没有 → 期望要点写「应拒答」；落题前先在 data/ 全库搜关键字确认 0 命中
> - **部分可答**（4 题）：语料有相关内容但答不全 → 期望要点写「可答的那部分」
> - 期望来源：写文件名（如 `请假制度.md`）；不确定写哪份就先搜关键字定位
> - 不编造语料里没有的答案；期望要点用你自己的话，一句话即可
>
> **判定列**：首次跑完 `eval_run.py` 后，对照打印出的 top-3 完整片段逐题填写：`命中` / `未命中`（无答案题留空）。
> **留出集（后 8 题）现在不跑** —— 调参结束后的最终检查才用（跑了就等于把它当开发集用了）。

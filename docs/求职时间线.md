**必须做的事**：建一个 `docs/投递记录.md`（表格：公司 / 岗位 / 投递日 / 状态 / 被拒原因 / 复盘）。**没有记录 = 没有复盘 = 重复踩同一个坑。**

**心态预期（提前植入，别到时候崩）**：11 月开始投的时候，你手上只有项目①，是全年最弱的时候 —— **前 30-50 份被拒是数据采集，不是失败**。这个阶段的目的是：① 摸清 JD 真实要求 ② 练习自我介绍 ③ 拿到面试反馈来校准学习重点。命中率低是预期的，不是对你能力的判决。

## 五、拿到实习怎么办（提前定好，免得到时候纠结）

> **先分清两类事件（2026-09-30 裁定）**：
> - **容量变化**（拿到实习 / 触发安全阀）→ **降强度 + 日期整体重排 + 内容按优先级削**：保 项目①②（RAG=毕设复用）/ 简历 / 投递；项目③可降级或砍（`ROADMAP` 砍单阶梯 3/4 档）。**不机械同时守「原日期 + 全部内容 + 降强度」**；拿到实习后先**重新测量可用时长**再排。
> - **估算超支**（进度落后、容量不变）→ 只砍内容，日期不动（`ROADMAP` 疲劳/进度仲裁表）。
> - 若容量变化确实使最低成果无法按时实现 → **明确延后范围，并尽早投递已有成果** —— 不用「最低线绝不动摇」覆盖客观容量。

**如果拿到日常实习（10 月-1 月期间）：**
- 学习节奏降到 **20 h/周**；先重测可用时长，再按上口径重排日期与内容
- 理由：**实习经历在简历上的权重高于「多一个项目」**。一边实习一边做项目，是最强的组合
- 注意：实习如果占满时间导致主线停摆，优先保主线 —— 一个"实习了半年但没作品"的人，不如"有实习 + 三个项目"的人

**如果拿到「实习转正」岗（2027 年 2 月后）：**
- 节奏放到最慢（15 h/周）；同样按「容量变化」口径重排
- 转正是 2027 届最现实的就业路径，**优先级最高**
